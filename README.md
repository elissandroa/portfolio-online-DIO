# Portfólio Online • Elissandro

👋 **Bem-vindo ao meu Portfólio Online!**

Este projeto é mais do que um simples site – é um espaço vivo onde apresento minhas habilidades, experiências e projetos de forma dinâmica, moderna e responsiva. Desenvolvido com **HTML, CSS e JavaScript**, ele reflete minha paixão por tecnologia, design elegante e soluções inteligentes.

---

## 🚀 Sobre o Projeto

Este portfólio foi construído com foco em recrutadores e parceiros que buscam profissionais criativos, organizados e antenados nas melhores práticas do mercado. Aqui você vai encontrar:

- **Apresentação pessoal** com foto e informações de contato rápidas
- **Habilidades técnicas** (Hard Skills) com ícones e visual moderno
- **Competências comportamentais** (Soft Skills) em destaque
- **Idiomas** que domino
- **Projetos e portfólio** com links diretos para aplicações e repositórios
- **Experiências profissionais** com descrição e período
- Layout responsivo, navegação por acordeão e animações suaves
- Integração dinâmica: dados carregados por um arquivo JSON, facilitando atualizações

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura semântica e acessível
- **CSS3** – Design responsivo, temas escuros e animações
- **JavaScript** – Manipulação dinâmica de dados e UI
- **JSON** – Fonte dos dados do perfil e projetos
- **GitHub Pages** – Hospedagem gratuita e fácil acesso

## 👨‍💻 Como Usar / Customizar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/elissandroa/portfolio-online-DIO.git
   ```
2. **Edite o arquivo `data/profile.json`** para atualizar suas informações.
3. **Abra o `index.html`** no navegador para ver as mudanças.
4. **Publique no GitHub Pages** para ter seu portfólio online!
